# KeyLauncher

ホットキーで呼び出して、名前を打ち込んで起動する Windows 用のキーボードランチャーです。

- スタートメニューのアプリ（デスクトップアプリ・ストアアプリ）を検索して起動
- フォルダー・ファイル・URL・コマンド（引数付き）を登録して検索
- 「めも」で「メモ帳」、「vsc」で「Visual Studio Code」のような、かな・頭文字での検索
- 登録項目には名前とは別に説明（和名など）を付けられ、どちらでも検索できる
- よく起動する項目ほど上位に表示

## 動作環境

- Windows 10 / 11（64 ビット）

## インストール

インストールは不要です。

1. [Releases](../../releases) から `KeyLauncher-v*-win-x64.zip` をダウンロードして展開します
2. `KeyLauncher.exe` を好きなフォルダーに置いて起動します（.NET ランタイムは同梱済みです）
3. タスクトレイに常駐し、`Alt + Space` で検索窓が開きます

ログイン時に自動で起動したい場合は、設定画面の「共通設定」で「Windows の起動時に KeyLauncher を起動する」をオンにします。
exe を別の場所に移したときは、移動先で一度オンにし直してください。

新しい版への更新は、トレイメニューの「更新を確認…」からできます（[アップデート](#アップデート)）。

アンインストールするときは、トレイメニューから終了し、`KeyLauncher.exe` と `%APPDATA%\KeyLauncher` フォルダーを削除します。
自動起動をオンにしていた場合は、削除する前にオフにしてください。

## 使い方

### ランチャー

| 操作 | キー |
| --- | --- |
| 検索窓を開く・閉じる | `Alt + Space`（設定で変更可） |
| 候補を選ぶ | `↑` `↓` |
| 起動する | `Enter`（またはクリック） |
| 番号の候補を直接起動する | `Alt + 1`〜`9` |
| 管理者として実行 | `Ctrl + Shift + Enter` |
| ファイルの場所を開く | `Ctrl + Enter` |
| パス・URL をコピー | `Ctrl + Shift + C` |
| フォルダーのパスをコピー（ファイル名を除く） | `Ctrl + Alt + C` |
| 操作メニューを開く | `Shift + F10`、アプリケーションキー（または右クリック） |
| 履歴から削除（未入力のとき） | `Shift + Delete` |
| 閉じる | `Esc` |
| 入力中の文字で新規登録 | `Ctrl + N` |
| 設定画面（登録項目）を開く | `Ctrl + E` |
| 設定画面（共通設定・ホットキー）を開く | `Ctrl + ,` |

何も入力していないときは、最近起動した項目が新しい順に表示されます。

### 設定画面

トレイアイコンの右クリックメニュー、またはランチャーの `Ctrl + E` から開きます。

- **登録項目**: フォルダー・ファイル・URL・コマンドの追加・編集・並べ替え。ファイルや URL をドラッグ＆ドロップしても追加できます
  - 名前とは別に「説明」（和名など）を付けられます。検索では名前と説明の両方から探し、ランチャーでは名前の横に表示します（例: 名前「tools」、説明「ツール置き場」なら、「tools」でも「つーる」でも見つかります）
  - 一覧で文字を打つと、名前がその文字で始まる項目に移ります（`t` で「tools」など。同じ文字をもう一度押すと次の項目へ）
- **共通設定**: 自動起動、ホットキー、スキン、フォルダー・ファイルを開くアプリ（標準のエクスプローラー／別のファイラーなど）、設定の移行、更新の確認
  - スキンは「キーボード」（既定）「ライト」「ミッドナイト」「ターミナル」「さくら」から、見本を見て選べます

### 設定の移行（エクスポート・インポート）

設定画面の「共通設定」→「設定の移行」で、登録項目と共通設定を 1 つの JSON ファイルに書き出し（エクスポート）、別の PC で読み込めます（インポート）。

- エクスポートは、設定画面に表示している内容（まだ保存していない変更も含む）を書き出します
- インポートした内容は画面に反映されるだけで、「保存」を押すまでファイルには書き込まれません。気に入らなければ「キャンセル」で元に戻せます
- 登録項目があるときは、ファイルの項目で**置き換える**か、今の項目に**追加する**かを選べます。追加のときは、パス（と引数）が同じ項目は追加しません
- 自動起動の設定（exe の場所に結びつくため）と、起動の履歴（`usage.json`）は移しません
- 移行先の PC でホットキーがほかのアプリに使われているときは、保存するときに知らせます。別の組み合わせを選んでください

#### ファイルの形式

```jsonc
// 先頭の // で始まる行はコメントです（読み込むときは無視します）
{
  "app": "KeyLauncher",
  "formatVersion": 1,
  "exportedAt": "2026-11-02T18:30:00+09:00",
  "settings": {
    "hotkey": "Ctrl+Space",
    "skin": "midnight",
    "useCustomOpener": true,
    "openerPath": "%LOCALAPPDATA%\\Programs\\MyFiler\\MyFiler.exe",
    "openerArgs": "\"{path}\"",
    "openFilesWithCustomOpener": false
  },
  "items": [
    { "name": "Downloads", "description": "ダウンロード", "path": "%USERPROFILE%\\Downloads" },
    { "name": "ターミナル（ホーム）", "path": "wt.exe", "args": "-d %USERPROFILE%" }
  ]
}
```

| キー | 内容 |
| --- | --- |
| `app` | 常に `"KeyLauncher"`。読み込むときは見ません |
| `formatVersion` | ファイル形式の版。今は `1`。これより新しい版のファイルは、KeyLauncher を更新するまで読み込めません。省略すると `1` とみなします |
| `exportedAt` | 書き出した日時。読み込むときは見ません |
| `settings` | 共通設定（下の表）。省略できます |
| `items` | 登録項目の配列。`items.json` と同じ形式です（下の表）。省略できます |

`settings` と `items` は、どちらか一方があれば読み込めます。`settings` に書いていない設定は、読み込む側の今の値のままになります（例: `{ "settings": { "skin": "sakura" } }` だけのファイルなら、スキンだけが変わります）。

`settings` に書けるキー:

| キー | 内容 | 例 |
| --- | --- | --- |
| `hotkey` | ランチャーを開くホットキー。読めない値は `Alt+Space` になります | `"Ctrl+Space"`、`"Ctrl+Alt+K"` |
| `skin` | スキン。知らない名前は無視して今のスキンのままにします | `"keyboard"`、`"keyboard-light"`、`"midnight"`、`"terminal"`、`"sakura"` |
| `useCustomOpener` | フォルダーを別のアプリで開くか | `true` / `false` |
| `openerPath` | 別のアプリの実行ファイル。環境変数が使えます | `"C:\\Tools\\MyFiler.exe"` |
| `openerArgs` | 別のアプリに渡す引数。`{path}` が開くパスに置き換わります | `"\"{path}\""` |
| `openFilesWithCustomOpener` | ファイルも別のアプリで開くか | `true` / `false` |

`items` の各項目に書けるキー（`items.json` と同じ）:

| キー | 内容 |
| --- | --- |
| `path` | フォルダー・ファイルのパス、URL、またはコマンド（必須。空の項目は読み飛ばします） |
| `name` | 検索に使う名前（省略するとフォルダー名・ファイル名・ドメイン名） |
| `description` | 名前とは別の説明（和名など）。名前と同じく検索の対象になります（省略可） |
| `args` | コマンドに渡す引数（省略可） |
| `workdir` | 作業フォルダー（省略可） |

- パスの `\` は `\\` のように 2 つ重ねて書きます。`%USERPROFILE%` などの環境変数が使えるので、PC ごとにユーザー名が違っても同じファイルを使えます
- コメント（`//` と `/* */`）と、末尾の余分なカンマは許されます
- `%APPDATA%\KeyLauncher\items.json`（項目の配列だけのファイル）も、そのままインポートできます

### アップデート

トレイメニューの「更新を確認…」、または設定画面の「共通設定」→「更新を確認」で、GitHub の最新リリースを確認します。
新しい版があれば、確認のあとでダウンロードして `KeyLauncher.exe` を置き換え、再起動します。設定はそのまま引き継がれます。

職場などのプロキシが認証を求めるときは、Windows のログオン情報で答えます。それで通れなければ、Windows の資格情報の入力画面を出します（入力したパスワードは KeyLauncher を通りません）。

### 設定ファイル

設定は `%APPDATA%\KeyLauncher` に保存されます。

| ファイル | 内容 |
| --- | --- |
| `items.json` | 登録項目（直接編集すると自動で反映されます） |
| `settings.json` | 共通設定（ホットキー、スキンなど） |
| `usage.json` | 起動回数と最後に起動した日時（履歴と並び順に使います） |
